# 150 题型模板与最短策略

本表只用于生成 candidate answer 和选择核验入口；candidate 不等于已核验答案。题目指定平台优先，动态值记录访问日期，登录或验证码立即转人工。

| 模板 | 最短策略 | 关键字段/输出 |
|---|---|---|
| A 平台菜单/功能 | 打开指定平台首页，按产品名或栏目名查菜单；只确认“存在/不在” | 菜单层级、功能名称、页面日期 |
| B 高级检索结果数量 | 选高级检索，按题干复现字段、时间、文献类型和匹配方式；只记结果总数 | 检索式、字段、筛选项、结果数、日期 |
| C 作者/机构/年份筛选 | 先完成一次检索，再用结果页左侧筛选或分析入口一次性配置条件 | 作者、第一单位、年份、来源类别、排序口径 |
| D PDF 页码/字符 | 优先原始 PDF；直接跳页后查标题、表格或字符，保留页码和短引文 | PDF URL、正文页码、目标字符/表名 |
| E 论文元数据 | 先查题名/DOI，进入详情页核对作者、参考文献数、页数和出版信息 | DOI、作者、页数、参考文献数、版本 |
| F 当前统计/排名 | 锁定平台和时间范围，完成筛选后记录当前值；不把动态值写成永久标准答案 | 指标、地区、人群、时间窗、值、日期 |
| G 视频前 10 秒/时长 | 公开页面可播放时只读时长或前 10 秒；播放器/DRM/登录即人工 | 视频 URL、时长、前 10 秒出现内容 |
| H App/微信功能 | 先确认题目要求的客户端、公众号、小程序或 App；需要扫码/登录不自动化 | 客户端、入口、按钮/菜单、人工截图 |
| I 办公快捷键/函数 | 本地静态知识或官方帮助先答；按软件版本核对一项即可 | 软件版本、快捷键、函数名、参数 |
| J 检索语法 | 先识别数据库，再查该库帮助页；不要混用 AND/OR、截词、字段语法 | 数据库、字段、运算符、通配符、示例式 |
| K AI 产品当前功能 | 只在官方产品页确认功能名称和入口；登录后功能标 NEEDS HUMAN | 产品版本、功能入口、权限、日期 |
| L 标准/专利/药品/资格 | 用编号、名称或注册号进入官方详情；原始正文优先 | 标准号/申请号/批准文号、日期、状态 |
| M 馆藏/古籍/课程章节 | 进入目录或馆藏入口，按书名、作者、索书号、课程和章节定位 | 题名、作者、馆藏地、章节、小节、页码 |
| N 多选逐项 UI | 原题命中直接按答案文本集合映射；新题找一页一次看全选项，逐项记录 A/B/C/D | 选项文本集合、每项证据、最终集合 |

## 统一决策顺序

1. 本地 SQLite：L0 题干+选项集合 → L1 标准化题干 → L2 相似题干 → L3 题干+选项内容。
2. 未命中时先输出 candidate，再按模板选择题目指定平台的单一路径。
3. 直接页面文本或 PDF 足够时不启动完整浏览器；必须 JavaScript、点菜单、筛选或读动态结果时，每题只选 Browser CLI 或 Playwright 一套，失败最多切换一次。
4. 原题命中且有 `standard_answer` 为 HIGH；用户模拟题的 `provisional_answer` 只作练习参考，不能覆盖官方标准答案。
5. 输出优先答案；attempt、截图、Markdown 和统计在答案之后轻量写入。单题硬超时 180 秒。

## 多选映射

按选项内容集合而不是字母顺序比较。已知题库选项为 `A/B/C/D` 时，将题库答案对应的选项文本与当前页面文本归一化后重新映射；发现重复选项或内容缺失时输出“需要核对选项内容”，不猜字母。
