# Mock Exam Patterns（指针）

CANONICAL SOURCE: skill/answer_patterns.md

本文件是**索引指针**，不是新内容。代码必须读取上面的 CANONICAL SOURCE，
不要解析本文件。项目里没有单独的 mock_exam_patterns.md，150 题提炼出的
题型模板已经存在于 canonical 文件。

## 实际模板清单（A–N，14 类）

| 模板 | 主题 | 对应 brief 里的题型 |
|---|---|---|
| A | 平台菜单/功能 | 当前网站菜单/功能、AI 产品当前功能 |
| B | 高级检索结果数量 | 数据库高级检索、结果数量比较 |
| C | 作者/机构/年份筛选 | 作者/机构/年份排名 |
| D | PDF 页码/字符 | PDF 具体页码、正文页码 vs PDF 页码 |
| E | 论文元数据 | 文献作者/参考文献/元数据、全文页数 |
| F | 当前统计/排名 | 统计数据、指数、词频 |
| G | 视频前 10 秒/时长 | 视频前几秒、视频时长 |
| H | App/微信功能 | 微信/App 操作 |
| I | 办公快捷键/函数 | Word/Excel |
| J | 检索语法 | 布尔检索、截词、精确/模糊 |
| K | AI 产品当前功能 | AI 产品当前功能 |
| L | 标准/专利/药品/资格 | 标准、专利、药品、资格信息 |
| M | 馆藏/古籍/课程章节 | 馆藏、古籍、课程章节 |
| N | 多选逐项 UI | 多选逐项核验 |

## 使用方式

新题不要从零思考：先在 `skill/answer_patterns.md` 里判定属于哪个模板，
再按该模板的「最短策略」选择单一路径，并输出该模板要求的「关键字段」。

模板只用于生成 candidate 和选择核验入口；candidate 不等于已核验答案。
