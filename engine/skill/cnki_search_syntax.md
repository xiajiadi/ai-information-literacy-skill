# CNKI 检索语法

来源：用户提供的 CNKI 官方检索手册
（https://piccache.cnki.net/index/helper/manuals.html#frame2-1-3）

**核心提醒：高级检索与专业检索语法不同，混用会导致检索式无效。**
给出人工交接检索式时，必须写明「界面上选哪个字段 + 框里填什么」。

---

## 专业检索

检索框内自带字段前缀。

| 代码 | 字段 | 代码 | 字段 |
|---|---|---|---|
| `SU=` | 主题 | `FU=` | 基金 |
| `TKA=` | 篇关摘 | `AB=` | 摘要 |
| `KY=` | 关键词 | `CO=` | 小标题 |
| `TI=` | 篇名 | `RF=` | 参考文献 |
| `FT=` | 全文 | `CLC=` | 分类号 |
| `AU=` | 作者 | `LY=` | 文献来源 |
| `FI=` | 第一作者 | `DOI=` | DOI |
| `RP=` | 通讯作者 | `CF=` | 被引频次 |
| `AF=` | 作者单位 | | |

官方示例：

```
TI='生态' and KY='生态文明' and (AU % '陈' + '王')
SU='北京' * '奥运' and FT='环境保护'
SU=('经济发展' + '可持续发展') * '转变' - '泡沫'
```

`%` 为模糊匹配：`AU % '陈'` 表示作者中含「陈」。
例 3 含义：「经济发展」或「可持续发展」有关「转变」的内容，并排除与「泡沫」有关的部分。

---

## 高级检索

检索项由界面下拉选定（篇名 / 主题 / 关键词 …），**框内只填裸表达式**。

规则：

- 支持 `*`(与) `+`(或) `-`(非) `''` `""` `()`
- 仅限**同一检索项内**组合运算
- 框内输入不超过 **120 个字符**
- 使用 `* + -` 时，优先级须用**英文半角括号**确定
- 检索词本身含空格或 `* + - ( ) / % =` 等符号时，须用**英文半角**单引号或双引号引起

官方示例：

```
神经网络 * 自然语言
(锻造 + 自由锻) * 裂纹
'digital library' * 'information service'
'2+3' * 人才培养
```

---

## 对照：同一个检索需求

| 界面 | 检索框内填写 |
|---|---|
| 高级检索（字段下拉选「主题」） | `'数字经济'*'税收'` |
| 专业检索 | `SU=('数字经济'*'税收')` |

---

## 其他平台

各平台检索语法**不通用**，不要把 CNKI 的写法套到万方、PubMed、IEEE Xplore 上；
用哪个平台就读哪个平台自己的帮助页，或在交接式中标注对应界面。
