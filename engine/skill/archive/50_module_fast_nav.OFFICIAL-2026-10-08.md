> **用途**：个人对抗 5 分钟 / 10 题的极速聊天模型“外置导航记忆”。目标不是替代完整题库，而是让模型在看到题目后迅速完成 **模块识别 → 首选入口 → 最短检索路径 → 风险判断**。

> **依据**：模块名称按赛事官方 50 模块体系；检索路径、陷阱和实操经验压缩自《省赛淘汰赛 · 交接题库》（42 道初赛真题 + 150 道模拟题 + 98 道公开样题）。题库中少量“知识模块XX”历史标签存在错位，本导航按官方模块语义重新归位，不以个别源标签为准。

## 0. 极速使用约定

- **先路由，后作答**：先判断 M01-M50，再决定直答、原站核验、计算或 PDF 定位。
- **动态 UI / 数字 / 排名 / 当前功能**：若未直接看到页面，不要给 90%+ 置信度。
- **官方源优先级**：赛事指定/政府/标准/数据库官方页 > 专业数据库 > 搜索聚合 > 模型记忆。
- **个人赛时间原则**：能靠稳定知识或明显排除直接答就立即答；需要多轮搜索的题应迅速降低置信度，不恋战。
- **多选题**：判断的是“整个组合完全正确”的概率，不是各选项分别看起来正确。

# AI素养（M01-M07）

## M01｜AI素养-AI基础知识与伦理规范
- **触发词**：AI法规、伦理、AIGC使用边界、UNESCO框架、规范文件、正文页码/表格
- **首选入口**：国家网信办/全国网安标委原文；UNESCO Digital Library；高校/科研机构官方规范
- **极速路径**：题目给文件名→找官方PDF→直接页内定位条款/页码/表格标题；问原则时先按文件适用范围区分。
- **易错/降置信度条件**：“正文页码”与PDF页码可能不同；相邻条款极易做成干扰项；AI印象不能替代原文。
- **答题模式**：`PDF定位 / 原文核验`
- **题库锚点**：`模拟-16`

- **极速路径**：法律名/主体/案号→选对应数据库→用唯一标识检索→打开详情核对金额/日期/文号。

## M11｜政府开放信息-标准与商标信息资源

- **极速路径**：标准号优先→详情/下载PDF→定位起草人、状态、发布日期；商标用注册号。
- **易错/降置信度条件**：标准“现行/作废/即将实施”与检索字段口径；题目可能把期刊收录信息混入。

## M12｜政府开放信息-专利和地理标志
- **触发词**：专利、申请号/专利号、同族、说明书、技术领域、附图、地理标志

- **答题模式**：`插件实操`
- **题库锚点**：`模拟-15`

## M40｜知识管理工具-截图与录屏
- **触发词**：QQ截图、贴图、录屏、快捷键、LICEcap、工具栏图标
- **首选入口**：QQ、LICEcap及软件内快捷键设置
- **极速路径**：直接启动工具→做一次截图/录屏→逐个核工具栏图标和快捷键。
- **易错/降置信度条件**：静态截图与QQ内置录屏口径可能不同；Win+G不是QQ。
- **答题模式**：`本机实操`
- **题库锚点**：`模拟-26` / `模拟-75` / `模拟-112`

## M41｜知识管理工具-PDF文件处理
- **触发词**：PDF转Word/合并/拆分/压缩/加密/加页、Office转PDF、PDF页数
- **首选入口**：Office内置导出、云展网PDF工具、具体论文/电子书PDF
- **极速路径**：工具题直接进云展网功能页；页数/图表题必须下载PDF并区分PDF页码与正文页码。
- **易错/降置信度条件**：“可编辑PDF”表述要谨慎；整书/章节PDF与网页页码不要混。
- **答题模式**：`PDF实操 / 页码核验`
- **题库锚点**：`模拟-24` / `模拟-70` / `模拟-71`

# 学术写作（M42-M45）

## M42｜学术写作-学术评价与投稿选刊
- **触发词**：影响因子、H指数、核心期刊、SCI/CSSCI/CSCD/AMI、智能选刊/选题分析
- **首选入口**：CNKI、万方、维普、百度学术分析、国家新闻出版署、CNKI写作投稿、LeapSpace
- **极速路径**：先确认期刊真伪/收录→再看评价指标；选题/选刊题进入对应平台模块核维度。
- **易错/降置信度条件**：综合影响因子/复合影响因子/H指数不是一回事；期刊收录版本有年度。
- **答题模式**：`期刊评价 / 原站核验`
- **题库锚点**：`模拟-10` / `模拟-52`

## M43｜学术写作-学术伦理
- **触发词**：学术不端、一稿多投、剽窃、AIGC学术边界、科研诚信
- **首选入口**：CY/T 174-2019、教育部相关办法、负责任研究行为规范、AIGC使用边界指南、万方科研诚信
- **极速路径**：行为描述→对照标准定义/例外→判断；问具体页码则下载标准PDF定位。
- **易错/降置信度条件**：退稿后再投通常不属于一稿多投；会议论文扩充后再投有条件例外。
- **答题模式**：`规范条文 / 情境判断`
- **题库锚点**：`模拟-41` / `模拟-59` / `模拟-90`

## M44｜学术写作-参考文献著录格式
- **触发词**：GB/T 7714-2025、APA、MLA、文献类型标识M/J/D/C/P/S、引文导出
- **首选入口**：国家标准、CNKI/万方/维普/百度学术引文导出
- **极速路径**：先判文献载体类型→对应标识→再看著录顺序与标点；格式题可用数据库导出作核验。
- **易错/降置信度条件**：选项字母与文献类型字母会故意混淆；“发表在页码”≠“引用了页码内容”。
- **答题模式**：`规则直答 / 格式核验`
- **题库锚点**：`模拟-4` / `模拟-68` / `模拟-130`

## M45｜学术写作-论文排版
- **触发词**：Word/WPS排版、替换、^p/^m/^g、标题样式、目录、分页、页眉页脚
- **首选入口**：Word/WPS本机功能、小恐龙公文排版助手
- **极速路径**：能本机试就直接试；特殊符号题进入“查找替换→特殊格式”；目录题先设置标题样式。
- **易错/降置信度条件**：Ctrl+Enter才是分页；特殊代码易混；源题库个别模块标签历史错位，按实际功能判断。
- **答题模式**：`本机操作 / 稳定知识`
- **题库锚点**：`模拟-31` / `模拟-84` / `模拟-93`

# 科研工具（M46-M50）

## M46｜科研工具-文献管理工具
- **触发词**：Zotero、Mendeley、知网研学、DOI/ISBN/PMID导入、文献管理
- **首选入口**：Zotero、Mendeley、知网研学E-study
- **极速路径**：添加条目→标识符/数据库/本地导入→核支持类型与同步/管理功能。

## M47｜科研工具-文献追踪工具
- **触发词**：RSS、Create alert、主题订阅、期刊订阅、学者订阅、文献追踪
- **首选入口**：PubMed、CNKI、万方智研平台
- **极速路径**：检索结果/期刊详情→Create alert/RSS/主题定制/订阅→核入口和分隔符等细节。
- **易错/降置信度条件**：CNKI RSS地址代码容易混；万方多个单位用分号而非逗号等UI细节会考。

## M48｜科研工具-数据处理工具
- **触发词**：Excel函数、LEFT/RIGHT/MID/FIND/TRIM/SUBSTITUTE/VLOOKUP/COUNTIFS/SUMIFS/INDEX/MATCH、数据清洗
- **首选入口**：Excel本机；开放数据集平台作为数据来源
- **极速路径**：先确定“提取/查找/条件统计/替换”任务→选函数→用最小示例心算或本机验证。
- **易错/降置信度条件**：MID起始位从1算；VLOOKUP返回列号相对区域；文本/数字类型会影响匹配。
- **答题模式**：`计算优先 / 可直接答`
- **题库锚点**：`模拟-17` / `模拟-49` / `模拟-62`

## M49｜科研工具-数据可视化工具
- **触发词**：ECharts、图表类型、3D示例、词云、微词云、可视化匹配
- **首选入口**：ECharts示例库、微词云、Excel图表/AI数据分析
- **极速路径**：图表库题直接进Examples；词云题导入全文→默认分词→看词频；选择图表先看变量类型。
- **易错/降置信度条件**：词频受分词/停用词参数影响；免费次数有限，比赛当天不要无意义消耗。
- **答题模式**：`可视化实操`
- **题库锚点**：`模拟-32` / `模拟-122`

## M50｜科研工具-文献可视化工具
- **触发词**：CiteSpace、VOSviewer、赛特新思、CNKI/万方/维普可视化、作者分布/发文趋势/知识图谱
- **首选入口**：赛特新思、CNKI/CNKI AI、万方、维普、CiteSpace/VOSviewer
- **极速路径**：先完成检索→进入“分析/可视化分析”→按作者、机构、年份、主题查看排序/网络。
- **易错/降置信度条件**：第一作者单位/作者单位口径影响排名；分析的是“当前检索结果”，检索条件必须先正确。
- **答题模式**：`检索后分析`
