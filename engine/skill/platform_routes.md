# 官方平台检索路线

下面的路线用于定位入口，不代替题目中的具体条件。每次作答仍要按题目指定的平台、年份、字段和统计口径复核。

## AI 素养：模块 01 至 07

- 模块 01：联合国教科文组织官网，查找《学生人工智能能力框架》原始 PDF 和正文页码；同时关注生成式 AI、科研诚信和 AI 伦理规范。
- 模块 02：阿里云开发者社区、科大讯飞 AI 大学堂、华为云开发者学堂昇腾专区、动手学深度学习、Elements of AI，以及高校图书馆 AI 专题页。
- 模块 03：DeepSeek、豆包、腾讯元宝、智谱清言、通义/千问、Kimi、讯飞星火、文心、纳米 AI 的网页版、App、小程序和浏览器插件。
- 模块 04：豆包、Kimi、通义/千问、智谱清言、文心和讯飞星火的 PPT、写作、数据处理及会议记录功能。需要登录时只给人工操作路径。
- 模块 05：CNKI AI、LeapSpace、星火科研助手、秘塔 AI 搜索、豆包和 AMiner。重点核对 Trust Card、Claim Radar、Deep Research、Writing Coach 和 CNKI AI 的模块位置。
- 模块 06：豆包、智谱清言、通义万相、可灵 AI、文心、讯飞星火、闪剪和蝉镜的图像、视频、音乐或数字人功能。
- 模块 07：GitHub 项目页的 README、License、Release 和更新时间；ModelScope 模型卡、数据集说明、许可证和下载入口。

## 政府开放信息：模块 08 至 16

- 模块 08：习近平系列重要讲话数据库等思政信息资源，按全文、题名、讲话时间和主题核对。
- 模块 09：国家统计局统计数据 → 数据查询；AI 知数按题目指标、地区和年份核对居民收入等统计值。
- 模块 10：中国法律知识资源总库、中国执行信息公开网，分别核对案例入口、案号、立案时间和执行信息。
- 模块 11：国家标准全文公开系统，按标准号或名称打开正文，记录页码、发布日期、实施日期和起草信息；国家商标信息查询按注册号或名称核对。
- 模块 12：国家知识产权局专利、商标、地理标志查询，按申请号、注册号、专利名称或权利人进入原文。
- 模块 13：中国互联网联合辟谣平台，进入“辟谣信息查证”并按来源、时间、分类和关键词筛选。
- 模块 14：国家药品监督管理局医疗器械和药品信息，CHKD AI 的知识问答和 PICO 分析；美国国会图书馆等指定馆藏页面按索书号核对。
- 模块 15：研招网硕士专业目录、高校信息素养教育数据库和相关教育资源，重点看专业、报考条件、专项计划和课程章节。
- 模块 16：学信网学历查询、证书资格查询等入口。涉及个人证书信息时不把真实个人数据写入本地记录。

## 学习资源与学术资源：模块 17 至 25

- 模块 17：中国大学 MOOC，按课程、教师、章节和小节标题定位内容。
- 模块 18：高校信息素养教育数据库，进入讲座、课程或视频栏目，核对期次、学校和主题。
- 模块 19：剑桥数据库等电子书平台，按书名和作者进入书目详情，核对全文入口、ISBN 和馆藏权限。
- 模块 20：国家图书馆数字资源，进入民国时期文献等专题库，核对书名、编者、页码和全文状态。
- 模块 21：CNKI、万方、维普和 Taylor & Francis，按题名、作者、年份、来源期刊、数据库收录和全文权限核验期刊论文。
- 模块 22：IEEE，进入 Upcoming conferences 或会议检索；按会议名称、时间、地点和官网状态核对。
- 模块 23：CNKI 学位论文、万方学位论文和高校机构库，按题名、导师、学校和学位类型核对。
- 模块 24：arXiv 按 identifier 或关键词检索，进入 Abstract、PDF 或 HTML 全文；同时区分 OA、预印本和正式出版版本。
- 模块 25：国家社科基金项目数据库等科研项目库，按项目名称、年度、负责人、单位和项目状态核对。

## 检索系统与技术：模块 26 至 37

- 模块 26：PubScholar、ACM Digital Library 和其他学术搜索平台，区分结果页、来源跳转和原文权限。
- 模块 27：指定图片搜索系统，确认是否支持以图识图、相似图片、图片来源和版权信息。
- 模块 28：中国古典文献资源导航系统，进入“古籍全文”栏目查看站点目录。
- 模块 29：百度指数，选择关键词、人群画像、地区和明确时间范围；动态值必须记录访问日期。
- 模块 30：图书馆馆藏查询，考虑中英文、不同版本、索书号、馆藏地和可借状态。
- 模块 31：CNKI 或万方高级检索，先选择文献类型，再配置多个字段和时间范围。
- 模块 32：用 AND、OR、NOT 组合主题、关键词、摘要或题名，检查括号和运算优先级。
- 模块 33：外文数据库截词符，核对星号、问号和词干匹配规则，不能把不同数据库语法混用。
- 模块 34：精确与模糊匹配，保留题目给出的默认匹配方式，并注意全角、半角和词序。
- 模块 35：结果筛选，核对左侧筛选项、文献类型、年份、来源类别和结果总数。
- 模块 36：字段限制检索，按篇名、作者、单位、第一单位、关键词、摘要和来源期刊选择检索点。
- 模块 37：搜索引擎高级检索，检查 site、filetype、intitle、关键词位置和时间限制等语法。

## 知识管理、写作和科研工具：模块 38 至 50

- 模块 38：腾讯文档、WPS、百度脑图、有道云笔记等思维导图、笔记和问卷工具，分别核对免费功能和导出格式。
- 模块 39：雨课堂、Office 插件和浏览器插件，确认插件适用版本、安装来源、功能范围和是否需要账号。
- 模块 40：QQ 截图、贴图、录屏和 LICEcap GIF 录制，按工具条图标和快捷键核对。
- 模块 41：Word、Excel、PPT 另存为 PDF；云展网 PDF 工具的合并、拆分、压缩、加密和格式转换。
- 模块 42：CNKI、万方、维普和国家新闻出版署期刊查询；CNKI 写作投稿服务和 LeapSpace 用于选题、选刊和投稿匹配。
- 模块 43：CY/T 174—2019、《高等学校预防与处理学术不端行为办法》和《负责任研究行为规范指引（2023）》；涉及 AIGC 时核对引用边界。
- 模块 44：GB/T 7714—2025、APA、MLA 及期刊自定义格式；从 CNKI、万方、维普导出题录后再对照标准。
- 模块 45：Word/WPS 的标题样式、目录、分节、页码、页眉页脚、脚注尾注、查找替换和批量合并。
- 模块 46：Mendeley、Zotero 和知网研学 E-study；按 DOI、内置数据库、学术搜索、第三方题录和本地上传添加文献。
- 模块 47：CNKI 主题定制和 RSS、PubMed Create RSS/Create alert、万方我的订阅；订阅动作需账号时转人工。
- 模块 48：Excel 的文本、查找、替换、连接、清洗、条件统计和查找函数；开放数据下载后先核对字段、样本、格式和缺失值。
- 模块 49：ECharts、Excel 图表、豆包数据分析和微词云；图表类型必须和数据类型匹配，词频结果记录文本版本和日期。
- 模块 50：CiteSpace、VOSviewer、赛特新思、CNKI、万方和维普的文献可视化，核对分析范围、排序口径和作者单位字段。

## 深链接优先（2026-09-19 补充）

题目写明平台时，**直接跳深链接**，不要从首页层层点击，也不要先走搜索引擎。
逐题 URL 配方以 `config/official_urls.json` 为准，本节只记最常用的跳法。

| 平台 | 直接入口 | route_type | Edge |
|---|---|---|---|
| CNKI 高级检索 | `https://kns.cnki.net/starter/advanced` | ADVANCED_SEARCH | 是 |
| 维普高级检索 | `https://www.cqvip.com/advancesearch` | ADVANCED_SEARCH | 是 |
| IEEE Xplore | `https://ieeexplore.ieee.org/search/advanced` | ADVANCED_SEARCH | — |
| ScienceDirect | `https://www.sciencedirect.com/search` | ADVANCED_SEARCH | — |
| LeapSpace | `https://www.sciencedirect.com/leapspace` | DEEP_LINK | — |
| CNIPA 专利常规检索 | `https://pss-system.cponline.cnipa.gov.cn/conventionalSearch` | DATABASE_ENTRY | 是 |
| CNIPA 官方导航 | `https://www.cnipa.gov.cn/col/col171/index.html` | HOME | — |
| 国家自然科学基金结题项目 | `https://kd.nsfc.cn/finalProjectInit` | DATABASE_ENTRY | — |
| 国家哲学社会科学文献中心 | `https://www.ncpssd.org/index` | HOME | — |
| 万方智研 | `https://zhiyan.wanfangdata.com.cn/` | HOME | 是 |
| 问卷星后台 | `https://www.wjx.cn/newwjx/manage/myquestionnaires.aspx` | LOGIN_DASHBOARD | 是 |
| 抖音创作者中心 | `https://creator.douyin.com/creator-micro/creator-count/arithmetic-index` | LOGIN_DASHBOARD | 是 |
| 中国大学MOOC | `https://www.icourse163.org/search.htm?search=<关键词>` | ADVANCED_SEARCH | — |
| UNESCO Digital Library | `https://unesdoc.unesco.org/ark:/48223/pf0000393559` | HOME | — |

**两条容易走错的路**：

- CNKI 不要直连 `kns8s/AdvSearch` 或 `kns8s/search` —— 会跳 blockPuzzle 安全验证；
  走 `starter/advanced` 可正常进入。
- ScienceDirect 首页被 Cloudflare 拦截（403，浏览器卡在「请稍候…」）；
  `/search` 可以直接进高级检索。

**万方是两条独立路由**：`WANFANG_MAIN`（主站检索）与 `WANFANG_ZHIYAN`（智研，
订阅 / 学科订阅 / 排序 / 被引量）。订阅类题不要从主站找入口。

**QUERY_RECIPE 型入口不只存 URL**：PubMed 配方同时保存 `expression` 与 `filters`
（见 `config/official_urls.json` 的 `query_recipe` 字段）。同型题只替换
关键词、字段标记、年份区间、NOT 条件与 Article type，不要重写整套检索式。

**登录态**：`prefer_edge` 为「是」的平台优先通过用户现有 Edge 打开。
本项目不读取、不导出 Cookie / Token / Session；也不把 `uid`、`randomt`、
`utm_*` 等参数写入任何文件（生成器会清洗）。

## 统一人工核验路径

打开题目指定官方平台，进入对应模块或高级检索入口，复制题目中的题名、作者、单位、年份、关键词或编号，设置筛选条件，记录题目要求的字段。若页面需要登录或验证码，停在登录前，把当前页面和要找的字段交给人工完成。
